# 刀塔战况（Dota 2 GSI）

把 Dota 2 官方接口这一局的实时数据交给她：英雄、血蓝、金钱、装备、比分，还有双方阵容、团战收口、敌方最后露头、肉山和建筑。

对局中出现变化时，扩展会推一条简短记录；没有新事件不重复发。她也可以随时主动读当前数据。

扩展只负责采集、传递和按预写规则归纳事实，不分析局势、不决定是否发言。要不要开口、说什么，由她判断。

> 作者基本只打加速（Turbo）模式，这一版在 Turbo 下连续用了很多天，挺顺手。普通模式的时刻表按官方数据配置，没经过长期实战——遇到提醒时间不对、团战口径不对这类问题，欢迎到 [Issues](https://github.com/YearDouble/cortico-world-dota2-gsi/issues) 反馈，附上面板调试区那一屏最好。

数据全部来自 Dota 2 官方本地接口，只读监听本机游戏，不操作游戏，不记录账号信息，不保存对局历史。

## 安装

**1. Steam 启动选项**

库里右键 Dota 2 → 属性 → 通用 → 启动选项。国服两项一起写：

```
-perfectworld -gamestateintegration
```

国际服只写 `-gamestateintegration`，顺序无所谓。2022 年 3 月之后 Dota 2 要这个启动项才会往外推数据。

**2. 写配置文件**

装好后打开扩展面板，点「写入 Dota 配置」。找不到游戏目录时，面板会给出路径和文件内容，手动放一样能用。这个文件只管自己，不动游戏里已有的其他 GSI 配置。

**3. 重启游戏**

启动选项和配置只在游戏客户端启动时读取，完全退出再开。面板上的「连接」变绿，说明数据到了。

## 她能看到什么

- 英雄、等级、血蓝、存活状态、沉默眩晕这类状态
- 金钱（可靠与不可靠）、GPM、XPM、净价值、击杀死亡助攻、补刀反补
- 身上装备、背包、中立装备和冷却；复活倒计时、买活价格与冷却；大招名字和是否就绪
- 比分、游戏时间、昼夜、防御塔、暂停；对局开始、结束和胜负
- 双方阵容：开局名单自动确认
- 团战：多人交火收口时报几换几、谁参与
- 地图动向：己方队友的实时位置区域；敌方每个人最后露头的时间和区域
- 四条固定动向提醒：敌方全员消失、三人以上抱团、消失的人出现在你附近、两人以上进肉山坑
- 敌方建筑被摧毁（带路别）、肉山被谁杀了、盾在谁手里、多久刷新
- 拾取提醒：莲花快熟、圣水符、第一颗经验符文（提前 30 秒，每局每条一次）

## 她看不到什么

- 敌方英雄的等级、对面每个人买了什么装备——接口不提供
- 敌方在迷雾里的实时位置，只有「最后露头在哪、多久之前」
- 地图画面、伤害明细、视野本身

## 工具

- `dota_status`：此刻这一局的卡。
- `dota_minimap`：现读位置库——己方在哪、敌方最后露头在哪、名单确认进度、肉山状态。
- `dota_events`：最近一段时间里发生过的变化。
- `dota_match`：一局的汇总，正在打就给到现在为止。

游戏没开或者没在打的时候，`dota_status` 会说清连接状态，并把手边上一局的数字给你。

## 设置

| 键 | 默认 | 说明 |
|---|---|---|
| `net.port` | 35123 | 本机监听端口，只绑 127.0.0.1。改完要重启 Coopanion 并重写配置 |
| `net.throttle` | 0.5 | 写进游戏配置的发送间隔（秒），越小越实时 |
| `net.heartbeat` | 10 | 写进游戏配置的心跳间隔（秒） |
| `timings.water1` / `water2` | 2:00 / 4:00 | 圣水符刷新时刻（秒），0=关 |
| `timings.lotus1` / `lotus2` | 常规 3:00 / 6:00，Turbo 1:30 / 3:00 | 莲花刷新时刻（秒），0=关 |
| `timings.wisdom1` | 7:00 | 第一颗经验符文（秒），0=关 |
| `timings.roshanFirst` | 常规 20:00，Turbo 0:00 | 肉山首刷时刻（秒），0=开局就在 |
| `timings.roshanRespawn` | 11 分钟 | 肉山复活基准（秒）；每次被打败减 1 分钟，最低 5 分钟 |
| `display.rawKeys` | false | 显示 `npc_dota_hero_nevermore` 这种原始键，排查用 |

**常规/Turbo 自动识别**：官方接口不报游戏模式，扩展从赏金符推断——首波金额（常规 ~40 金，加速给双倍）开局几十秒就能判出来；肉山在 20:00 前露头直接判加速；判不出来时按常规时刻表走，但卡片不标模式——宁缺勿错。面板调试区能看到当前判断、赏金符金额和实测值。

版本更新改了时间，先在设置里救急改，不用等发版。

## 名字

包里自带 127 个英雄和常用装备的中文名，卡片和记录直接说「影魔」「闪烁匕首」。

想换自己的叫法，在扩展的 data 目录放一份 `dota2-gsi/names.zh.json`：

```json
{ "heroes": { "nevermore": "影魔（我自己的叫法）" }, "items": { "blink": "跳刀" } }
```

同名的条目覆盖包里的，其余照旧，发版也不会冲掉。

## 面板

连接状态、当前卡片、最近二十条事件，以及「写入 Dota 配置」「复制配置内容」「复制原始帧」「喂一段测试数据」「重试监听」几个按钮。

排查顺序：红灯是没收到报文（先看启动选项写了没），绿灯但读不到数字是报文装配问题，数字正常但她不提是提示词的问题。

## 卸载

关掉 Coopanion，删掉扩展；再把游戏目录里的 `gamestate_integration_coopanion.cfg` 删掉。Steam 启动项里的 `-gamestateintegration` 可以留着，Logitech 这类软件也要用它。
