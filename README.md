# 刀塔战况（Dota 2 GSI）

将 Dota 2 官方接口提供的实时对局数据传递给 Coo，包括：

英雄、等级、生命值、魔法值、金钱、补刀、战绩、装备及冷却时间、复活与买活时间、双方比分、游戏时间和昼夜状态，以及对局的开始和结束时间。

对局中出现状态变化时，会向 Coo 发送简短记录，没有新事件时不会重复发送。Coo 也可以随时主动读取当前的最新数据。

扩展只负责采集和传递数据，不负责分析局势或决定是否发言。如何理解这些数据、是否据此作出回应，由 Coo 自行处理。

数据仅来自 Dota 2 官方本地接口，范围限于本机玩家可以获取的信息。击杀者身份、敌方装备、其他玩家在地图上的动态等接口未提供的数据，无法获取。

接口由官方提供，无三方风险，只读监听本机游戏，不操作游戏，不记录账号信息，不保存对局历史。

## 安装

**1. Steam 启动选项**

库里右键 Dota 2 → 属性 → 通用 → 启动选项。国服两项一起写：

```
-perfectworld -gamestateintegration
```

国际服只写 `-gamestateintegration`，顺序无所谓。2022 年 3 月之后 Dota 2 要这个启动项才会往外推数据。

**2. 写配置文件**

装好后打开扩展面板，点「写入 Dota 配置」。找不到游戏目录时，面板会给出路径和文件内容，手动放一样能用。

这个文件只管自己，不动游戏里已有的其他 GSI 配置。

**3. 重启游戏**

启动选项和配置只在游戏启动时读取，完全退出再开。

面板上的「连接」变绿，说明数据到了。

## 她能看到什么

- 英雄、等级、血蓝、存活状态、沉默眩晕这类状态
- 金钱（可靠与不可靠）、GPM、XPM、净价值
- 击杀、死亡、助攻、补刀、反补
- 身上装备、背包、中立装备和冷却
- 复活倒计时、买活价格与冷却
- 大招名字和是否就绪
- 比分、游戏时间、昼夜、防御塔、暂停
- 对局开始、结束和胜负

## 她看不到什么

- 谁杀了你、敌人现在在哪
- 对面买了什么、队友的装备
- 地图画面、视野、团战过程

这一版 GSI 也还没有肉山刷新计时。这些不是扩展省掉了，是游戏本身就不发。

## 工具

- `dota_status`：此刻这一局的卡。
- `dota_events`：最近一段时间里发生过的变化。
- `dota_match`：一局的汇总，正在打就给到现在为止。

游戏没开或者没在打的时候，`dota_status` 会说清连接状态，并把手边上一局的数字给你。

## 面板

面板上有连接状态、当前卡片、最近二十条事件，以及「写入 Dota 配置」「复制配置内容」「复制原始帧」「喂一段测试数据」「重试监听」几个按钮。

排查顺序：红灯是没收到报文，绿灯但读不到数字是装配问题，数字正常但她不提是提示词的问题。

## 卸载

关掉 Coopanion，删掉扩展；再把游戏目录里的 `gamestate_integration_coopanion.cfg` 删掉。Steam 启动项里的 `-gamestateintegration` 可以留着，Logitech 这类软件也要用它。
